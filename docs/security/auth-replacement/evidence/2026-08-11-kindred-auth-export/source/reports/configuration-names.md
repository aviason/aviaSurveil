# Configuration names (values intentionally excluded)

Only configuration names are listed here. Values, defaults, credentials, URLs, key material, deployment environment files and secret-bearing examples are not exported.

## Auth/runtime names

`APP_ENV`, `SERVICE_NAME`, `AWS_REGION`, `USERS_TABLE`, `APP_TABLE`, `UPLOADS_BUCKET`, `S3_ENDPOINT`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `DYNAMODB_ENDPOINT`, `TOKEN_TTL_SECONDS`, `REFRESH_TOKEN_IDLE_TTL_SECONDS`, `REFRESH_TOKEN_ABSOLUTE_TTL_SECONDS`, `JWT_PRIVATE_KEY_PEM`, `JWT_PRIVATE_KEY_SSM_PATH`, `JWT_PRIVATE_KEY_PATH`, `JWT_ISSUER`, `JWT_AUDIENCE`, `TRANSPARENCY_SIGNING_KEY_B64`, `TRANSPARENCY_SIGNING_KEY_SSM_PATH`, `REQUIRE_VERIFIED_EMAIL`, `EMAIL_VERIFICATION_TTL_SECONDS`, `PASSWORD_RESET_TTL_SECONDS`, `PHONE_VERIFICATION_TTL_SECONDS`, `RETURN_PHONE_VERIFICATION_CODE`, `MAX_FAILED_LOGIN_ATTEMPTS`, `LOCKOUT_DURATION_SECONDS`, `AUTH_RATE_LIMIT_MAX`, `AUTH_RATE_LIMIT_WINDOW_SECONDS`, `RATE_LIMIT_TABLE`, `MOBILE_DEEP_LINK_SCHEME`, `LOCAL_HTTP_ADDR`.

## Delivery/telemetry names adjacent to identity

`MAIL_FROM`, `MAIL_PASSWORD`, `MAIL_SMTP_HOST`, `MAIL_SMTP_PORT`, `SMS_WEBHOOK_URL`, `SMS_WEBHOOK_TOKEN`, `ANALYTICS_ENABLED`, `ANALYTICS_FIREHOSE_STREAM`, `ANALYTICS_SCHEMA_VERSION`.

## Infrastructure names observed but not trusted by the current Go signer

`TOKEN_SECRET`, `token_secret_ssm_path`, and `jwt_private_key_ssm_path` appear in Terraform/deployment plumbing. `TOKEN_SECRET` is legacy HMAC configuration and is not read by the current Go RS256 implementation. This mismatch is documented as a blocker; no values are included.

## Non-auth application limits kept for boundary context

`UPLOAD_URL_TTL_SECONDS`, `DOWNLOAD_URL_TTL_SECONDS`, `THREAD_BASE_PRICE`, `THREAD_DEMAND_STEP`, `THREAD_DEMAND_MULTIPLIER_STEP_PCT`, `THREAD_MIN_COST`, `THREAD_MAX_COST`, `DELIVERY_BASE_REWARD`, `DELIVERY_RATING_BONUS_PER_STAR`, `DELIVERY_MIN_REWARD_RATING`, `REPEAT_RECIPIENT_REWARD_COOLDOWN_DAYS`, `NEW_ACCOUNT_ACTIVE_THREAD_LIMIT`, `ACTIVE_THREAD_LIMIT`, `NEW_ACCOUNT_AGE_DAYS`, `MESSAGE_THREAD_MAX_SERVER_MESSAGES`, `MESSAGE_CLOSED_RETENTION_DAYS`, `STOREKIT_BUNDLE_ID`, `STOREKIT_PREMIUM_MONTHLY_PRODUCT_ID`, `STOREKIT_ENVIRONMENT`, `STOREKIT_ENABLE_ONLINE_CHECKS`, `SEED_USER_EMAIL`, `SEED_USER_PASSWORD`, `SEED_USER_DISPLAY_NAME`, `SEED_USER_CITY`, and `SEED_DEMO` are listed by name only for completeness; values and seed files are excluded.
