# NCAA Operational Checklists Submission Package

**Status:** PENDING SOURCE DOCUMENTS — do not submit yet.

**Requested submission date:** 2026-08-07

## Purpose

This package is the controlled assembly location for the request for current
operational checklists and the corresponding Sectional/Departmental Checklist
Register. It deliberately contains no repository product specifications,
demo scenarios, regulatory-source copies, generated candidates, or unverified
checklists. Those materials are not evidence that a current operational
checklist is maintained and controlled by an NCAA section or department.

## Before submission

1. Place each approved current operational checklist in `SOURCE-INBOX/` using
   the original controlled filename. Do not overwrite a source file.
2. Record one row for every submitted checklist in `CHECKLIST_REGISTER.csv`.
3. Complete all required fields, including owner section/department, document
   identifier, controlled revision, effective date, review date, and status.
4. Add every source file's SHA-256 value to `MANIFEST.sha256`.
5. Change `manifest.json` status to `READY_FOR_OWNER_REVIEW` only after the
   responsible section/department owner has confirmed the register.
6. Change it to `READY_FOR_SUBMISSION` only after the final owner confirms the
   complete file set. Use `SUBMISSION_EMAIL_DRAFT.md` for the outgoing email.

## Explicit boundary

This package is an administrative collection aid. It does not approve,
publish, modify, or attest to any operational checklist. Missing source
documents must remain visible as missing; they must not be replaced with
product, demo, regulatory, generated, or inferred content.
